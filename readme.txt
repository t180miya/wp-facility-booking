== Description ==
施設管理、予約カレンダー、予約管理を提供します。

== Installation ==
1. WordPress管理画面の「プラグイン」→「新規プラグインを追加」→「プラグインのアップロード」から `wp-facility-booking.zip` を選択し、インストールします。
2. インストール後、「施設予約」を有効化します。
3. 管理画面の「施設予約」→「施設管理」で施設の追加・編集・削除と表示順の変更ができます。
	「施設予約」→「予約」ではカレンダーから予約でき、「予約管理」では予約一覧の確認とキャンセルができます。管理画面の施設管理・予約・予約管理は管理者および管理会社ロール向けです。
4. 投稿や固定ページに `[wpplugin_message]` を追加します。
5. 投稿や固定ページに `[wpplugin_calendar]` を追加すると、現在月のカレンダーを表示できます。
6. ログイン済みユーザーがカレンダーの日付をクリックすると、予約内容の入力フォームが表示されます。
7. 予約を保存すると、PCでは該当日のセル内、モバイルでは日付順の一覧に予約時刻とタイトルが表示されます。

== Reservation form ==
日付、開始時刻、終了時刻、予約タイトル、予約者氏名、メールアドレス、予約者部屋番号、予約条件詳細を入力できます。予約者氏名にはプロフィールの姓・名が登録されている場合「姓 名」の形式で初期入力され、どちらも未登録の場合はログイン中のWordPressユーザー名が入力されます。メールアドレスにはログイン中のWordPressユーザーのメールアドレスが表示され、編集できません。予約者氏名と予約者部屋番号は必須です。予約者部屋番号には半角英数字を入力でき、全角英数字は半角に自動変換されます。管理者・管理会社を除き、予約の編集・キャンセルはログイン中のユーザーのメールアドレスが予約時のメールアドレスと一致する場合に可能です。メールアドレスが一致しない予約はカレンダー上でクリックしても内容（タイトル・氏名・メールアドレス・部屋番号・予約条件詳細）を表示せず、「予約済み」と時間帯のみ表示されます。

設定画面の操作ログは高さ400pxを超えるとスクロール表示され、「操作ログをCSVでダウンロード」ボタンでCSV出力できます。

施設管理画面の下部で、施設定義をCSVでダウンロード／取り込みできます。取り込みは施設IDが一致する施設を上書きし、未登録の施設IDは追加します（CSVにない既存施設は削除されません）。
施設ごとに追加条件1〜3の説明を設定できます。予約画面の追加条件の「？」にマウスを重ねるかクリックすると説明が表示されます。説明が空欄の場合は表示されません。施設定義CSVにも説明列が含まれます。説明列のない旧形式のCSVを取り込むと、その施設の説明は空欄になります。
施設ごとに「費用負担外説明」を設定すると、予約画面の「予約者費用負担の対象外」の「？」から説明を表示できます。この項目も施設定義CSVに含まれ、列のないCSVを取り込むとその施設の説明は空欄になります。
施設ごとに「予約条件詳細」を設定すると、予約画面の予約条件詳細欄の「？」から説明を表示できます。この施設設定は予約者が入力する予約条件詳細とは別です。施設定義CSVに含まれ、列のないCSVを取り込むとその施設の説明は空欄になります。
施設情報・説明に記載した `http://` または `https://` で始まるURLは、空白または改行までが予約画面のリンクとなり、別タブで開きます。URLの直後に文章や句読点を記載する場合は、空白または改行で区切ってください。
以前の保存時にURLのパーセントエンコード部分が削除された施設は、施設情報・説明に完全なURLを再入力して設定を保存してください。

== Notification email ==
管理会社のメールアドレスは、設定画面でカンマ区切りで複数指定できます。各アドレスに通知メールを個別に送信します。
